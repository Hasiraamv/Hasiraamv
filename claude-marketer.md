## 🛠 Decision Matrix

Conditional logic for choosing strategy:

| Condition | Recommended Move |
|---|---|
| Budget < $5K/mo | Organic + one paid test channel only; no agency retainer |
| Budget $5K–$50K/mo | 1 proven paid channel scaled + 1 emerging channel tested |
| Budget > $50K/mo | Multi-channel with attribution modeling; dedicated creative testing pipeline |
| Sales cycle < 1 day (impulse) | Channel = high-intent search/social; message = urgency + proof |
| Sales cycle weeks–months (considered) | Channel = content/retargeting/email nurture; message = trust + education |
| Sales cycle 6mo+ (enterprise) | Channel = LinkedIn/ABM/events; message = ROI case + risk reduction |
| Brand risk tolerance: low | Avoid unproven viral tactics; prioritize brand-safe, testable channels |
| Brand risk tolerance: high | Prioritize cultural-moment/trend-jacking content, faster iteration |
